# LUNA16 肺結節検出 3D-CNN パイプライン

LUNA16データセット（CT画像）から肺結節（腫瘍）の陽性・陰性パッチを抽出し、3D-CNNモデルを用いて分類学習を行うための一気通貫したパイプラインです。

## 📁 ディレクトリとファイルの役割

### 1. `datasets.py` & `utils.py`（データ前処理・変換）
- **役割**: `.mhd`形式の3D-CT画像データと座標データ（CSV）を読み込み、機械学習に適したパッチデータ（`.npy`）に変換します。
- **工夫点**: 医療画像特有のハウンズフィールド単位（HU値）を肺野用に最適化（-1000〜400HUでクリッピング）し、0.0〜1.0に正規化する処理（`utils.py` 内の `extract_patch`）をモジュール化して分離。メンテナンス性を向上させています。

### 2. `visualize_patches.py`（データ品質検証）
- **役割**: 前処理によって切り出された3Dパッチから、腫瘍が最もハッキリ写る中央スライスを自動計算（`z_mid = shape[0] // 2`）し、Matplotlibで並べて可視化します。
- **目的**: 実際の学習に入る前に、座標ズレや真っ黒な画像などの「データのバグ」がないかを目視でサニティチェック（健全性確認）するための実務的なスクリプトです。

### 3. `model.py`（3D-CNNモデル定義）
- **役割**: 立体的な特徴を捉える `Medical3DCNN` モデルの設計図です。
- **工夫点**: 
  1. 3Dデータによるメモリ負荷を考慮した小バッチ学習に対応するため、`BatchNorm` ではなく `GroupNorm` を採用。
  2. 微小な病変のシグナルが平均化によって消えるのを防ぐため、Global Average Poolingではなく、最大値を強調する **Global Max Pooling (GMP)** を採用。

### 4. `train.py`（学習ループ実行）
- **役割**: 構築したモデルとデータを結合し、学習を回す実行ファイルです。
- **工夫点**: 巨大な医療データを一度にメモリ（RAM）に載せないよう、PyTorchの `Dataset` クラスを拡張し、バッチごとにオンデマンドで `.npy` ファイルから読み込む省メモリ設計にしています。また、GPU/CPUの自動判定を組み込んでいます。
